Маленькая текстовая RPG на Python.

Что есть:

    ⚔️ Бой с монстром (удар/блок)

    🎰 Казино (слоты, джекпот)

    🛒 Магазин оружия (секира / двуруч / катана — множитель урона)

    💾 Сохранения в saves/*.json (баланс + множитель)

    📜система сохранения действий в логи logs/log.log

Управление: при старте 1 — загрузить сейв, 2 — начать с нуля. Дальше вводить цифры пунктов меню (1 — бой, 2 — казино, 3 — магазин, 4 — выход с сохранением).

Требования: только стандартная библиотека Python 3. Папка saves/ и logs/ создаются автоматически.
