# 🎮 PvE Telegram Bot & Console Game

Текстовая RPG, которая начиналась как простой консольный скрипт, а теперь выросла в полноценного Telegram-бота с модульной архитектурой.

## 🚀 Что нового?
Проект переведен с одного огромного файла на модульную структуру. Теперь каждая часть программы отвечает за свою зону ответственности:
*   `PvE_bot.py` — главный файл бота (хендлеры, диспетчер кнопок, запуск).
*   `game_logic.py` — игровая логика (класс `character`, расчеты урона и блоков).
*   `database.py` — работа с файловой системой (сохранения в JSON, логи, чтение токена).
*   `tg_utils.py` — вспомогательные функции для Telegram (обработка ошибок `safe_edit`).
*   `PvE.py` — старая консольная версия игры (архив).

## ⚔️ Игровые механики:
*   **Бой с монстром:** Пошаговая система с ударами и блоком (блок срезает 75% урона).
*   **Казино:** Слоты с генерацией случайных символов. Есть джекпот, возврат ставки и полный проигрыш.
*   **Магазин:** Покупка оружия для увеличения множителя урона (Секира / Двуручный меч / Катана).
*   **Сохранения:** Прогресс каждого игрока (баланс и урон) сохраняется в отдельный JSON-файл по его Telegram ID.
*   **Логирование:** Все важные действия игроков записываются в личные логи (`logs/ID.log`).

## 🛠️ Как запустить (Telegram-бот)

1. Установите библиотеку для работы с Телеграмом:
   ```bash
   pip install python-telegram-bot
   ```
2. Создайте файл `api.json` в корневой папке проекта и добавьте туда токен от `@BotFather`:
   ```json
   {
       "TOKEN": "ТВОЙ_ТОКЕН_ЗДЕСЬ"
   }
   ```
3. Запустите бота:
   ```bash
   python PvE_bot.py
   ```

*(Папки `saves/` и `logs/` создаются автоматически при первом запуске).*

## 🕹️ Как играть
Отправьте боту команду `/start`. Управление происходит полностью через инлайн-кнопки. Бот не требует ввода текста, всё интуитивно понятно.

## ⚠️ Важно для контрибьюторов
Убедитесь, что в вашем `.gitignore` добавлены файлы `api.json`, папка `saves/` и `logs/`, чтобы не залить в репозиторий токен бота или личные данные игроков.
