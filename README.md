# 🎮 PvE Игра и Telegram-бот

Текстовая RPG на Python, в которой есть всё, чтобы скрасить вечер: кровожадные монстры, азартное казино и магазин с оружием. 

Проект существует в двух версиях:
1. **PvE.py** — классическая консольная игра.
2. **PvE_bot.py** — полноценный Telegram-бот (работает на `python-telegram-bot`).

## ⚔️ Что есть в игре:

*   **Бой с монстром:** Механика с ударами и блоком. Монстры могут быть опасны, если не вовремя ставить защиту.
*   **Казино:** Слоты с генерацией случайных символов. Есть джекпот, возврат половины ставки и полный проигрыш. Выиграть сложно, но можно.
*   **Магазин оружия:** Улучшай свой множитель урона (Секира / Двуручный меч / Катана). Нельзя купить оружие хуже того, что у тебя уже есть.
*   **Сохранения:** В боте сейвы привязаны к Telegram ID игрока (папка `saves/`), в консоли — к имени файла. Данные хранятся в JSON (`balance`, `mult_dam`).
*   **Логирование:** (В консольной версии) Все действия игроков записываются в файл `logs/log.log`.

## 🛠️ Как запустить

### 1. Консольная версия (`PvE.py`)
Тебе понадобится только стандартная библиотека Python 3. 
```bash
python PvE.py
```
При запуске игра спросит, хочешь ли ты загрузить сейв (1) или начать с нуля (2). Дальше управление идет через ввод цифр в консоль.

### 2. Telegram-бот (`PvE_bot.py`)
Для запуска бота тебе понадобится:
*   Установленная библиотека: `pip install python-telegram-bot`
*   Файл `api.json` с твоим токеном от `@BotFather`:
    ```json
    {
        "TOKEN": "ТВОЙ_ТОКЕН_ЗДЕСЬ"
    }
    ```
*   Запуск: `python PvE_bot.py`

*(Совет: если запускаешь с телефона, используй Termux и не забудь отключить оптимизацию батареи для него).*

## 📁 Структура проекта

*   `PvE.py` — консольная версия игры.
*   `PvE_bot.py` — Телеграм-бот.
*   `api.json` — конфиг с токеном бота (не светить в паблике!).
*   `saves/` — папка с JSON-файлами сохранений (создается автоматически).
*   `logs/` — папка с логами (создается автоматически).
